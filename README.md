# Calming Petopia

A cozy pet town game for people with big feelings. Play it at **https://calmingpetopia.com**

Adopt pets, care for them, earn coins, do yoga, climb math walls and find the hidden scrolls.
The art is hand drawn in pencil and the music is played on recorder, viola and clarinet, all by kids.

This repository only holds the built site. `index.html` is the whole game in one file
(code, pictures and sounds are all inside it), and GitHub Pages serves it at the custom domain in `CNAME`.
